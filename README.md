# 🕵️‍♂️ Secret Mission - مهمة سرية

رحلة تصميم واجهات مستخدم وتجربة مستخدم (UI/UX) للعبة جماعية بالكامل داخل Figma 🎨🔥 من فكرة الشاشات للبروتوتايب التفاعلي..

> *"سرّك بيدك.. وعينك على غيرك"*  
> لعبة جماعية تفاعلية للأجهزة الذكية تعتمد على الغموض، تنفيذ المهام السرية، والتصويت لكشف المتخفين.

## 💡 عن المشروع
تم تصميم وتطوير هذه اللعبة لتقديم تجربة مستخدم سلسة، تفاعلية، وممتعة للجلسات الجماعية. تركز رحلة التصميم على:
* بناء تسلسل بصري واضح ومريح للعين.
* محاكاة الحالات المختلفة للشاشات عبر مكونات فيجما التفاعلية.
* ضمان تجربة لعب سريعة وخالية من التعقيد.
